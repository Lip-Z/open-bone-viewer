# OpenBone Viewer

**自己的片子，看得更明白。**

OpenBone Viewer 是一个给普通人使用的 CT、X 光与三维影像查看器。如果你拿到了医院的影像，却不知道怎么打开，或者想对照检查报告认识身体里的位置和形状，可以从这里开始。

它在自己的电脑上运行，使用中文界面，无需账号。你可以逐层查看 CT、旋转三维外观，也可以放大 X 光。遇到不熟悉的按钮，点击页面上的 **“看不懂？点这里”**，查看入门、CT、三维、X 光和隐私答疑。

当前是 **0.1.0 首个公开版本**，源码采用 [MIT 许可证](LICENSE)。真实患者影像不包含在项目里。

## 它能帮我做什么？

- **打开自己的影像。** 导入医院提供的影像文件、文件夹或 ZIP，也能查看 PNG、JPG 等普通图片。
- **从不同方向看同一个部位。** CT 的三个窗口相互联动，点击一个位置，可以在另外两个方向找到它。
- **认识三维形状。** 旋转、放大和移动 CT 生成的三维外观，帮助理解二维切片之间的关系。
- **把 X 光看清楚一些。** 放大、移动，调整亮度和对比度；随时恢复初始显示。
- **把疑问整理得更具体。** 对照报告确认自己想问的是哪个部位、哪一层，再与医生交流。

这里的答疑解释影像和操作方法，不读取你的病历作诊断，也没有接入在线 AI。软件不能仅凭三维外观判断骨折是否愈合、病情是否严重，或现在能否负重、运动。这些结论需要结合原始影像、报告、症状和查体。

## 我需要准备什么文件？

优先向医院索取 **“完整的 DICOM 原始影像”**。它可能在光盘、U 盘、下载的 ZIP 或一个包含很多文件的文件夹里。有些文件没有扩展名，不必逐个重命名，直接选择整个文件夹或 ZIP 即可。

| 手上的资料 | 可以做什么 |
| --- | --- |
| CT 的完整 DICOM 序列 | 支持的序列可以逐层查看、从三个方向看，并生成三维外观 |
| X 光的 DICOM 文件 | 查看二维影像，放大、移动和调整显示 |
| PNG、JPG、WebP、BMP 图片 | 查看二维图片；清晰度取决于图片本身 |
| 纸质报告、PDF 报告、胶片照片或截图 | 本软件不读取报告；照片或截图不能代替完整 CT 生成真实三维结构 |

第一次打开时，也可以先试用 **合成示例**。它由程序生成，帮助熟悉操作，不是其他患者的片子。

## 第一次怎么启动？

这一版还没有打包成直接安装的桌面软件。可以先前往 [v0.1.0 Release](https://github.com/Lip-Z/open-bone-viewer/releases/tag/v0.1.0)，在 **Assets** 中下载 GitHub 自动生成的 **Source code (zip)**，解压到方便的位置。然后安装 **Python 3.12 或更新版本**、**Node.js 22.12 或更新版本**，再启动项目。首次启动会联网下载运行组件，可能需要等待一会儿；完成后，日常查看影像可以离线进行。

目前已在 Windows、Python 3.12 和 Chromium 浏览器上实际运行验证。GitHub Actions 还在 Ubuntu 和 Windows 上通过了自动化测试与前端构建；macOS、Linux 的完整桌面启动和浏览器交互尚未实测。

**Windows：** 下载或取得完整项目文件夹后，双击 `启动查看器.cmd`。保留打开的服务窗口，浏览器会自动进入 [本机查看器](http://127.0.0.1:4318)。这个地址只在你的电脑上使用。

**其他平台，或需要查看启动日志：** 在项目目录运行：

```sh
python run.py
```

关闭服务窗口即可停止。只关闭浏览器页面不会停止服务，重新打开本机地址可以继续查看。安装遇到问题时，请保留错误提示，参见 [启动选项与开发说明](docs/development.md)。

## 三步开始看自己的片子

### 1. 导入影像

点击 **“打开我的片子”**，选择文件或 ZIP；资料是一个文件夹时，点击 **“选择整个文件夹”**。也可以把文件拖进页面。处理在本机完成，较大的 CT 需要多等一会儿。

一次导入可能出现好几组 CT：它们可能是同一次检查中不同方向、层厚或方式的重建，也可能来自不同检查。组数本身不代表检查次数或病情轻重。可以先打开一组受支持的序列；如果提示暂不支持，换其他连续切片组试试。

### 2. 先看二维，再转一转三维

打开 CT 后，三个切面是 **同一份 CT 从不同方向看**，不是三次检查：

| 窗口 | 怎么理解 |
| --- | --- |
| 横着看（横断位） | 像从身体横向切出一层，逐层上下移动 |
| 正面看（冠状位） | 像从身体正面看，逐层向前或向后移动 |
| 侧面看（矢状位） | 像从身体侧面看，逐层向左或向右移动 |

在切片上滚动或拖动滑块，可以换一层；点击影像，另外两个方向会定位到同一个位置。**“看骨骼 / 看软组织 / 看肺部”** 只是不同的明暗显示方式，切换不会改动原始数据，也不会自动识别病变。

三维窗口里，拖动旋转，滚轮缩放，右键拖动平移。右上角的恢复视角按钮可以找回初始视角。三维方便认识形状；需要核对细节时，回到二维切片。

打开 X 光或普通图片后，可以直接放大、拖动；想调亮度和对比度时，展开下方的 **“更多显示调整与导出”**。这里的调整只改变屏幕显示，不会让原片产生新的细节。

### 3. 看不懂时，打开对应答疑

点击 **“看不懂？点这里”**，或影像旁的答疑入口，查看当前操作的解释。先用基本功能就够了；想进一步生成表面模型或保存结果时，再展开 **“更多调整与导出”**。

“三维外观”用于直观浏览；“表面模型”按照你选择的密度范围提取表面，可以导出 STL。两者都可能包含多块骨、支具或扫描床，不会自动分离出某一块骨。调整参数、平滑或选区会改变生成结果，外观更光滑也不等于扫描更准确。

## 常见问题

### 三维里有裂缝、缺口，就说明没有长好吗？

不能仅凭这个下结论。扫描层厚、显示参数和表面生成方式都可能影响三维外观；它也不能单独说明关节软骨、稳定性或承重能力。可以记录看到的位置，再结合原始切片和检查报告讨论。

### 为什么三维里有床板，或者少了一部分？

“主体预览”会尝试隐藏与主体分开的物体，也可能隐藏分开的身体部位；与身体相连的支撑物仍可能留下。切换到 **“全部结构”** 可以查看完整三维显示。这个切换只影响三维预览，不会删除原始切片，也不会改变表面模型的生成输入。

### 提示“暂不支持”，是不是我的片子有问题？

不一定。这一版只支持部分常见影像格式和排列方式。斜切、机架倾斜、层间距不规则、多帧 CT，以及扫描前的定位片，目前不能生成三维；MRI 也不支持。程序会说明原因。同次检查有其他重建序列时，可以尝试打开；[完整支持范围](docs/development.md#支持范围与限制)供需要的人核对。

### 可以直接打开医院的云胶片链接吗？

目前不能。请先从医院下载影像文件，再导入本机。软件不连接医院系统，也不会索取医院账号。

### 能用一张 X 光、截图或报告生成三维吗？

不能。当前三维来自完整且受支持的 CT DICOM 序列。X 光和普通图片只按二维显示，软件不会补画看不到的结构。

### 我的片子会被上传吗？

查看器在本机处理影像，不使用云端模型、统计脚本或外部字体。首次安装运行组件需要联网；导入影像后，程序会在本机另外保存一份副本和生成结果。

**本地处理不等于自动脱敏。** 导入副本仍可能包含姓名、生日和医院信息，影像上已经印出的姓名也不会被自动擦掉。分享截图或导出文件前，请检查是否含有个人信息。

### 文件存在哪里？删除检查会删掉医院原片吗？

默认数据位置：

- Windows：`%LOCALAPPDATA%\OpenBoneViewer`
- macOS：`~/Library/Application Support/OpenBoneViewer`
- Linux：`~/.local/share/OpenBoneViewer`

检查列表里的删除操作会清除该检查在软件中的本地数据；同次导入的其他序列仍在使用的文件会保留。**不会删除或改写你最初选择的医院文件。** 自己另外下载、复制的结果需要自行管理。

### 可以保存什么？

在 CT 的 **“更多调整与导出”** 中可以保存 CT 数据（NRRD）或已生成的表面模型（STL）；X 光的 **“更多显示调整与导出”** 中可以保存显示图片（PNG）。一般浏览不需要导出。STL 是三维表面，不能代替原始 CT；显示 PNG 也不能代替原始 DICOM，且不包含页面上临时调节的亮度、对比度与缩放。导出结果同样属于个人医疗资料。

想进一步了解检查原理，可以阅读 ACR / RSNA 面向公众的 [CT 介绍](https://www.radiologyinfo.org/en/info/bodyct) 和 [骨骼 X 光介绍](https://www.radiologyinfo.org/en/info/bonerad)（英文）。这些外部资料用于解释一般原理，不是对个人影像的判断。

## 开源与参与

项目从个人查看影像的实际需要出发，希望让更多人能打开自己的片子，并带着更明确的问题参与就医沟通。项目已在 [GitHub](https://github.com/Lip-Z/open-bone-viewer) 公开；当前 [v0.1.0 Release](https://github.com/Lip-Z/open-bone-viewer/releases/tag/v0.1.0) 提供源码归档。

欢迎改进易懂的说明、无障碍操作、文件兼容性和显示性能。反馈“这里看不懂”同样有帮助，可提交到 [GitHub Issues](https://github.com/Lip-Z/open-bone-viewer/issues)。请不要把真实患者影像、原始文件名、姓名、截图或运行目录提交到公开讨论中；尽量使用合成示例复现问题。
